# 吉他抽签网站：发布与分享指南

已完成可公开部署的纯静态网站，无需安装依赖、运行构建或配置服务器。本文按 2026 年 11 月 2 日可查的官方文档整理；平台界面名称可能调整。

## 交付文件

- `guitar-lottery/index.html`：正式网站入口，所有样式与功能都在这一文件内。
- `guitar-lottery/.nojekyll`：GitHub Pages 辅助文件，无需修改。
- `guitar_lottery.html`：同一网站的单文件副本，方便双击试用。正式部署建议使用文件夹中的 `index.html`。
- `guitar-lottery-发布包.zip`：解压后得到可直接部署的 `guitar-lottery` 文件夹。

文件不依赖外部字体、图片、脚本或服务。部署目录的第一层必须能看到 `index.html`。

## 已保留的功能

1. 原始 10 款型号：PAC612、PACS+12、AZ224F、AZ24P1QM、MIJ Aerodyne Special Stratocaster HSS、American Professional II Stratocaster HSS、Edwards E-SNAPPER-AL、Pro-Mod Plus DK24 HSS 2PT、Schecter BH-1-STD-24、az2203。
2. 动态抽签转盘：每个型号等概率，结果与顶部指针落点一致；允许重复抽中，转动期间锁定清单编辑，避免重复点击。
3. 增加、删除型号：最多 30 款，单款最多 100 字符，忽略大小写拒绝重复项。清单为空时禁止抽签。
4. 恢复初始 10 款：需要确认，保留已有记录。
5. 保存最近 100 次抽签记录与时间；支持确认后清空。
6. 分享当前清单：将型号写入链接，朋友打开后主动点击“导入清单”，自己的记录仍保留。不会分享历史记录。
7. 手机布局、键盘操作、结果语音辅助提示与减少动画偏好支持。

原始型号拼写按你的列表保留，没有推断或更换具体产品。

## 方案一：Netlify 拖拽发布（操作最少）

1. 解压发布包，找到 `guitar-lottery` 文件夹，打开确认第一层有 `index.html`。
2. 在浏览器访问 [Netlify Drop](https://app.netlify.com/drop)。建议登录自己的 Netlify 账号，便于日后管理与更新。
3. 将整个 `guitar-lottery` 文件夹拖到上传区域。使用文件夹最直观；不要只上传发布指南。
4. 等待上传和发布完成，在项目页面打开平台返回的生产站点链接。
5. Netlify 会分配形如 `https://平台分配的名称.netlify.app/` 的地址。这里是格式示例，实际地址以项目页面为准。
6. 如果想换地址名称，在项目的设置中查找项目名称或站点名称设置；修改能否成功取决于名称是否可用。自定义域名是可选项，无需购买域名也可以分享平台地址。
7. 用手机或无痕窗口打开这个链接，点击抽签确认正常，然后把它发给朋友。

更新网页：打开同一个 Netlify 项目，在 **Deploys** 页的手动上传区域重新上传更新后的完整文件夹。不要每次都新建项目，以免生成不同网址。生产地址保持使用同一项目的地址。

这是已经可以发布的成品，不需要构建命令，也不需要填写任何密钥。

官方说明：[Create deploys](https://docs.netlify.com/deploy/create-deploys/)、[Manage deploys](https://docs.netlify.com/deploy/manage-deploys/manage-deploys-overview/)。

## 方案二：GitHub Pages（github.io 地址）

### 1. 创建仓库并上传文件

1. 登录 [GitHub](https://github.com)，新建仓库，例如 `guitar-lottery`。
2. 选择公开仓库（Public），可勾选添加 README，然后创建。
3. 在仓库首页点击 **Add file → Upload files**。
4. 上传解压后的 `guitar-lottery` 文件夹内的 `index.html` 和 `.nojekyll`，然后提交（Commit changes）。macOS 默认隐藏 `.nojekyll`，可按 `⌘⇧.` 显示；若不方便，单独上传 `index.html` 也能发布这个网站。
5. 在仓库首页确认 `index.html` 就在根目录，与 README 同级。不要上传成 `guitar-lottery/index.html` 这个嵌套结构，也不要只上传 ZIP。

### 2. 开启 Pages

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment** 下，将 **Source** 设为 **Deploy from a branch**。
3. **Branch** 选择上传文件所在的分支，通常是 `main`；目录选择 **/(root)**。
4. 点击 **Save**，等待 Pages 发布完成。
5. 刷新 Pages 设置页，打开页面显示的站点地址。若尚未完成，可在仓库 **Actions** 页查看 `pages build and deployment` 的执行状态。
6. 项目仓库的网址通常形如 `https://你的用户名.github.io/guitar-lottery/`。这是格式说明，实际地址以 Pages 页面显示为准。

如果你专门创建名为 `你的用户名.github.io` 的仓库，站点可位于 `https://你的用户名.github.io/`。普通项目仓库无需这样命名。

更新网页：在同一个仓库替换根目录 `index.html` 并提交，Pages 会重新发布。待部署成功再刷新站点。

官方说明：[配置 GitHub Pages 发布源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 怎么发给朋友

- **发默认网站**：复制发布平台返回的 HTTPS 网站地址。新访客首次打开会看到原始 10 款吉他。
- **发你修改后的清单**：在已发布的网站中增删型号，再点击“分享当前清单”，点击“复制链接”。朋友用该链接打开，点击黄色提示中的“导入清单”。此链接包含那一刻的清单快照；你后续再修改时需要重新分享链接。
- **地址太长**：自定义清单写在链接的 `#models=…` 部分，型号多时链接会变长。应完整复制，不要截断；如果聊天软件不识别，可让朋友复制完整文本到浏览器。
- **记录独立**：每个人、每个浏览器、每个网站地址分别保存自己的清单和记录。网站没有账号、共享数据库、多人同步或公共排行榜。

这里把“oi 版本”按“可分享网址 / io 版本”处理。网页文件不能凭空产生公网域名，`file://…` 和本机预览地址都不能发给朋友直接访问。必须完成上述任一发布流程，才能拿到真正的公开网址。

## 怎样改变所有新访客看到的默认型号

网页里的增删操作只修改你当前浏览器的数据。若希望所有新访客默认看到新的琴单，需要编辑 `index.html` 中的 `DEFAULTS` 数组，再重新部署。保留合法的 JavaScript 字符串格式，避免重复型号。已有访客保存过清单时仍使用自己的清单，可点“恢复初始 10 款”重新读取当前网页的默认清单。

## 使用与保存说明

- 直接双击 `guitar_lottery.html` 可试用抽签功能；本地文件模式下会提示先发布再分享。
- 型号与记录保存在浏览器的 localStorage 中。刷新和普通关闭后会保留；清理网站数据、某些隐私模式或浏览器限制可能导致数据丢失，页面会在保存失败时提示。
- 本地文件、Netlify 地址和 GitHub Pages 地址是不同的保存空间，记录不会自动迁移。
- 页面不发送抽签记录，也未接入分析统计。托管平台仍按其规则处理普通访问请求。分享链接只携带型号。
- 抽签使用浏览器随机数生成能力，每款同等机会；展示的概率保留一位小数，因此相加时可能有四舍五入差异。
- 它用于选琴娱乐，不提供产品价格、配置或购买建议。

## 发布后快速验收

1. 新开无痕窗口，确认显示 10 款型号。
2. 点击抽签，转盘停止后检查指针所在的型号编号与结果一致，历史增加一条。
3. 添加一个测试型号，刷新页面，确认型号与记录保留；再删除测试型号。
4. 点击“分享当前清单”，复制链接，在另一个浏览器打开并导入，确认型号一致、记录不被分享。
5. 在手机竖屏检查按钮和清单能正常使用。

## 常见问题

- **GitHub Pages 404**：确认 Pages 已部署成功，文件名为小写 `index.html`，位于选择的发布目录；普通项目地址需要包含仓库名路径。
- **Netlify 404**：检查拖拽文件夹第一层是否为 `index.html`，重新上传完整文件夹。
- **网页还是旧内容**：先确认平台部署成功，再刷新或用无痕窗口查看。已有访客的本地清单不会因网页更新而自动覆盖。
- **朋友没看到我新增的琴**：分享已发布页面中的“分享当前清单”链接，并让朋友点击“导入清单”；只发基础网址不会传递你的本地修改。
- **复制链接失败**：对话框会选中链接，按 `⌘C` / `Ctrl+C` 或手机长按复制。
